4. 결론

  1. 도메인 fine-tuning 자체는 매우 효과적 — 학습한 약은 0%→99.94%. 사전학습 PP-OCR 의 음각 인식 불능을 결정적으로 해소.
  2. 50종으론 운영 일반화 불가 — 학습에 없는 임의의 약은 못 읽음(데이터로 정량 확인). 사용자 촬영 9알약이 그 증거.
  3. 의사결정 근거 확보 — 임의 약 커버리지를 위해선 AIHub 전체 ~5,000종(Training 스플릿) 확보·재학습이 실제로 필요함이 입증됨. 파이프라인(데이터준비→학습→평가→배포 훅)은 이미 구축· 검증되어, 데이터만 확보되면 동일 절차로 확장 가능.
