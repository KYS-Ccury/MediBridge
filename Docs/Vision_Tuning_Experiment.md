## 2. 정답표 (Ground Truth)

크롭 육안 판독으로 확정. 각인은 **사람이 읽을 수 있는 경우만** 정답으로
채점에 포함(흐려서 판독 불가한 것은 각인 채점 제외 = N/A).

전체 9알약 중 R1 에서 7개 검출. 미검출 2개(다크네이비 오벌, 흰색
오블롱/캡슐로 추정)는 검출률 지표에만 반영.

| GT# | 색 | 모양 | 각인(육안) | 비고 |
|---|---|---|---|---|
| G1 | 파란색 | 원형 | M G | 라이트블루, 흰 글자 (crop #0) |
| G2 | 흰색 | 원형 | KG | crop #1 또는 #3 |
| G3 | 흰색 | 원형 | KG | crop #3 또는 #1 |
| G4 | 연두 | 원형 | HA | 연녹/연두, crop #2 |
| G5 | 흰색 | 원형 | N/A | 로고형 음각, 판독 불가 (crop #4) |
| G6 | 분홍 | 원형 | N/A | 연분홍, 음각 매우 흐림 (crop #5) |
| G7 | 흰색 | 원형 | N/A | 음각 흐림 (crop #6) |

> 동일 의미로 간주. KG/HA 도 공백·대소문자 무시하고 영숫자만 비교.

## 3. 측정 지표

- **검출률** = 검출 crop 수 / 9
- **색 정확도** = (색 정답 일치 crop) / (검출 crop)
- **모양 정확도** = (모양 정답 일치 crop) / (검출 crop)
- **각인 정확도** = (각인 정답 일치) / (각인 채점대상 중 검출된 것)
  - 일치 기준: 영숫자만 추출·대문자화 후 정답과 부분일치(정답이
    OCR 결과에 포함 또는 그 역) 시 정답 처리

크롭 인덱스↔GT 매핑은 라운드마다 crop 좌표가 거의 동일하므로
육안 1회 확정 후 고정. (YOLO 출력 순서가 라운드 간 바뀔 수 있어
색/모양/각인은 "검출된 crop 들"을 GT 집합과 다대다 대응해 best
매칭으로 채점.)

### R2 — 모양 contour 안정화

**변경 파라미터 (ShapeClassifier 만, 색/OCR 불변):**
- `_largest_contour`: Otsu+polarity 후 **MORPH_CLOSE**(타원커널
  k≈min변/12, 2회) 추가 — 각인/반사로 생긴 전경 구멍·노치 메움
- `_classify_from_contour`: **convex hull** 적용 (알약은 볼록)
- 모양 임계 변경:
  - before: ratio≥2.5 캡슐 / ≥1.3 장방 / ≥1.1 타원 / else 원
  - after : ratio≥2.3 캡슐 / ≥1.45 장방 / (≥1.25 또는 circ<0.78)
    타원 / else 원

**측정 결과:**

| 단계 | 변경 | #0 circ | #0 모양 | 회귀 |
|---|---|---|---|---|
| R2(중간) | close+hull 만 | 0.34→**0.80** | 타원형 | #1·#5 원형→타원형 (종횡비 1.10~1.17 가 1.1 임계 침범) |
| R2b(임계조정) | 임계 1.1→1.25 + circ<0.78 | 0.80 | **원형** | 회귀 해소 |

R2b raw: 7개 전부 `원형` (circ 0.80~0.99, e 1.01~1.17).

**채점 (검출 7, GT 검출분 G1~G7 전부 원형):**
- 모양 = **7/7 = 100%** ✅ (목표 90% 초과)
- 색 = 5/7 = 71.4% (불변 — #2 연두→흰색, #5 분홍→흰색)
- 각인 = ~17% (불변)
- 검출률 = 7/9 (불변)

**무엇이 개선에 도움이 됐는가 (사실):**
- convex hull: 글자/반사로 생긴 외곽 노치 제거 → circularity
  0.34→0.80, 다른 원형들 0.89→0.96~0.99 로 안정화. 결정적.
- MORPH_CLOSE: 전경 분리(각인) 병합 보조.

**무엇이 악화로 이어졌는가 (사실):**
- hull 적용 직후, 둥근 알약의 minAreaRect 종횡비가 1.10~1.17 로
  상승해 기존 1.1 타원형 임계를 침범 → #1·#5 가 원형→타원형으로
  일시 회귀. 임계를 1.25 로 올리고 circ<0.78 보조조건을 추가해
  해소(R2b).

**해석 (추측 포함):**
- hull 후 종횡비가 오른 것은, 노이즈 contour 의 minAreaRect 가
  우연히 정사각에 가깝던 것이 hull 로 알약의 실제 약한 타원성을
  반영하게 된 결과로 추정된다. 즉 1.1 임계 자체가 과민했고 hull
  이 그것을 드러낸 것으로 생각된다.

촬영 방식 변경(① 알약을 프레임 가득 근접 촬영 ②/또는 폰이 화면
