# samples/ — 테스트 사진 폴더

본 폴더에 **여러 알약을 한 사진에 담은 테스트용 이미지** 를 넣어주세요.

## 권장 촬영 가이드

- **배경**: 단색 (흰 종이·접시 등). POC 단계의 OpenCV 검출은 단순 배경에서만 잘 동작
- **조명**: 그늘 없이 균일하게. 손그림자 X
- **카메라 거리**: 알약이 사진 한 변의 1/8 ~ 1/3 차지하도록
- **각도**: 정면 위에서 촬영
- **여러 알약**: 서로 충분히 떨어뜨려 (윤곽선 분리가 필요)
- **각인**: 또렷하게 보이도록. 흐릿하면 OCR 실패율 높음

## 지원 확장자

`.jpg / .jpeg / .png / .bmp / .tif / .tiff`

## 주의

본 폴더의 사진은 `.gitignore` 로 git 추적 제외됩니다 — 개인정보·민감정보 포함 가능성을 고려한 정책입니다. 본 README 만 git 추적됩니다.

## 빠른 테스트 시드

가장 빠르게 검증하려면:

1. 흰 종이 위에 **시중 약 2~3알** (서로 다른 색·모양으로) 올림
2. 폰 카메라로 위에서 정면 촬영
3. PC 의 본 폴더로 옮김 (USB·네트워크 등)
4. 상위 폴더에서: `python detect_pills.py samples/`

처음 실행 시 PaddleOCR 가 모델 가중치를 자동 다운로드 (~수십 MB, 1회만).
