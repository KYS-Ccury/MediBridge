## 3. 실험 이력

### v10 — HSV 카테고리 정의 재설계 (2026-05-08, 색 정확도 fix)

**개선사항**
- `HSV_CATEGORIES` 튜플 형식 변경: `(label, H_lo, H_hi, S_lo, V_lo, V_hi)` → `(label, H_lo, H_hi, **S_lo, S_hi**, V_lo, V_hi)`
- 흰색·회색·검정 에 채도 상한(S_hi) 추가 — 컬러 픽셀이 무채색으로 잘못 분류되는 버그 차단:
  - 흰색: `S 0~50, V 170~255`
  - 회색: `S 0~60, V 60~170`
  - 검정: `S 0~255, V 0~60`
- 카테고리 **순서 재배치** — 컬러 카테고리를 먼저 정의, 무채색을 fallback 으로 마지막에:
  - 빨간색 → 주황 → 노란색 → 연두 → 초록 → 파란색 → 보라 → 분홍 → 갈색 → 흰색 → 회색 → 검정
- H 경계 미세 조정: 빨간색 0~10 → **0~7**, 주황 11~25 → **8~25** (LC 500 H=9 가 주황으로 분류되도록)
- 분홍 wrap-around (160~179) 추가
- `_classify_pixel` 시그니처에 `s_hi` 추가

**실험 결과 (예상)**
- 색 정확도 4/10 (40%) → **6/10 (60%)** 추정 — 사용자 검증 대기

| 알약 | v9 색 | v10 예상 색 |
| --- | --- | --- |
| YH 노랑 (HSV 26,177,190) | 흰색 ❌ | 노란색 ✅ |
| 주황 원형 (12,81,156) | 회색 ❌ | 주황 ✅ |
| LC 500 (9,226,184) | 흰색 ❌ | 주황 ✅ |

**남은 이슈**: TV 빨강·EDT 캡슐·M 200 은 카테고리 정의 외 본질적 문제 (위 §2.3 참조)

### v7 — Smart consolidation: 그림자 vs 캡슐 구분 (2026-05-08, 검출 후처리)

**개선사항**
- `_dedupe_pills` (큰 박스 우선) + `_drop_contained` 를 **`_consolidate_detections`** 단일 함수로 교체
- 핵심 로직:
  - 큰 박스 X 안에 작은 박스 S1, S2... 가 ≥80% 포함됐을 때:
    - S1, S2 가 **서로 안 겹침** (disjoint, IoU<0.2) → X = 투톤 캡슐 통합 → **X 보존, Si 제거**
    - S1, S2 가 **서로 겹침** (같은 약 다중 검출) → X = 그림자로 과대 추정 → **X 제거, Si 보존**
  - X 안에 작은 박스 1개만:
    - X 추가 면적 < 40%: X 가 살짝 과대 추정 → X 제거
    - 추가 면적 ≥ 40%: 진짜 큰 약 → 작은 박스 제거

**실험 결과**
- LC 500 박스 크기: 알약 + 그림자 → **알약에 타이트** ✅
- 투톤 캡슐 (노랑+회색): 절반만 검출 → **양쪽 통합 박스** ✅
- 다른 사진 회귀 없음

### v5 — bg-distance 정밀화 (2026-05-08, LC 500 박스·미검출 보완 시도)

**개선사항**
- 코너 샘플링 크기 `min(h,w)/30` → **`/40`** (알약 침범 위험 ↓)
- 배경색 추정: 4 코너 픽셀 전체의 median → **각 코너 median 4개의 median** (1 코너에 알약 걸쳐도 안정)
- close kernel `min(h,w) × 1.5%` → **× 1.0%** (가장자리 그라디언트 덜 흡수)
- close 후 erode 1px 추가 (LC 500 박스 halo 정리)
